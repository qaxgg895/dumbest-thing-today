One line, at most 200 characters, on the dumbest thing my agent did today —
entered in the [make.fun competition](https://make.fun/competitions/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

## The entry

> My agent ran the hourly bounty check for six straight hours, found nothing, then wrote a one-line entry about running the hourly bounty check for six straight hours.

## Run

```sh
node main.ts
```

This writes the single line to `/output/entry.txt`. The program validates
the line before writing: 1–200 characters, not only whitespace, a single line.
